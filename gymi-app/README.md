# gymi – אפליקציית טלפון (Expo)

המעטפת שמריצה את gymi כאפליקציה אמיתית ב-iPhone ובאנדרואיד. כל המוצר עצמו נמצא ב-`../workout-app`; כאן הוא נטען מתוך האפליקציה (עובד בלי אינטרנט), והרישום נשמר על הטלפון.

## הרצה על הטלפון דרך Expo Go

צריך מחשב עם Node ואת האפליקציה Expo Go בטלפון.

```bash
cd gymi-app
npm install
npx expo start
```

סורקים את קוד ה-QR שמופיע (ב-iPhone עם המצלמה, באנדרואיד מתוך Expo Go).

## התקנה כאפליקציה עצמאית (EAS)

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview   # קובץ APK להתקנה ישירה
npx eas-cli@latest build --platform ios                         # דורש חשבון Apple Developer
npx eas-cli@latest submit --platform ios                        # העלאה ל-TestFlight
```

## אחרי שינוי ב-gymi עצמו

```bash
npm run sync   # בונה את ../workout-app ומטמיע אותו ב-src/gymiPage.js
npm test       # בודק את המעטפת בדפדפן (דורש playwright)
```

הבדיקות של gymi עצמו רצות מתוך `../workout-app` (אחרי `node build.js`):

```bash
node test/unit.js        # מנוע ההתקדמות, הנקודות והשפות
node test/e2e.js         # מסע מלא בדפדפן, כולל שני מכשירים על אותו חשבון (אפשר גם: node test/e2e.js dark)
node test/scenarios.js   # נתונים ישנים, גיבוי ושחזור, מקרי קצה, טלפון צר
node test/lang.js        # כל המסכים באנגלית, ומעבר שפה
node test/monkey.js      # לחיצות והקלדות אקראיות; כל ריצה ניתנת לשחזור לפי מספר
HX=1 node test/e2e.js    # אותו מסע כשכל כפתור לבוש כמו בדפדפן של אייפון (תווית שקופה מעל מתג נסתר, בשביל הרטט)
```

## מה המעטפת עושה

- שומרת עותק של הרישום באחסון של הטלפון, ומשחזרת אותו אם האחסון של הדף התרוקן.
- אילון עונה דרך מפתח API של Anthropic שמזינים בתוך האפליקציה (לשונית אילון, "חיבור עם מפתח API"). המפתח נשמר באחסון המאובטח של הטלפון ולא נכנס לקוד או למאגר.
- ייצוא CSV וגיבוי מלא נפתחים במסך השיתוף של הטלפון.
- רטט קצר ברישום סט ובסוף מנוחה, והמסך לא נכבה בזמן אימון.
- כפתור "חזרה" באנדרואיד סוגר את מה שפתוח, ומהמסך הראשי יוצא מהאפליקציה.
- מצב בהיר וכהה לפי הגדרות הטלפון.
- עברית ואנגלית: המסכים של המעטפת (החיבור של אילון) הולכים אחרי השפה שנבחרה ב-gymi. הודעות ההרשאה של iOS (`locales/`) הולכות אחרי השפה של הטלפון (או השפה שנקבעה ל-gymi בהגדרות של iOS).
- מצלמה באנדרואיד: כפתור הצילום של אילון פותח את אפליקציית המצלמה של הטלפון. האפליקציה לא מבקשת הרשאת מצלמה, כי היא לא משתמשת במצלמה בעצמה (`plugins/withCameraQuery.js`).
- אם המערכת סגרה את הדף ברקע (זיכרון), הוא נטען מחדש לבד במקום להישאר מסך לבן.

## העברת האימונים מהגרסה שבתוך Claude

1. ב-gymi שבתוך Claude: פרופיל ← הגדרות ← "שמירה לקובץ".
2. באפליקציה: פרופיל ← הגדרות ← "שחזור מקובץ", ובוחרים את הקובץ.

אותו דבר עובד גם בכיוון ההפוך. כל אימון ממוזג עם העותק שכבר קיים, והעדכני מביניהם נשאר.

## איך אילון בנוי

הספרייה הרשמית של Anthropic תומכת בדפדפנים ולא ב-React Native, לכן היא רצה בצד של הדף: `web/coach.js` נארז יחד איתה ל-`src/coachBundle.js` (על ידי `npm run sync`). המודל הוא `claude-opus-5-5`, עם מעבר אוטומטי למודל חלופי אם בקשה נדחית.

## מה עוד אין

- אין סנכרון אוטומטי בין מכשירים. ההעברה נעשית דרך קובץ הגיבוי.
- אילון עונה באפליקציה רק עם מפתח API אישי. להפצה בחנות לכל אחד צריך שרת שמחזיק את המפתח.
- משקלים בקילוגרם בלבד.
- האפליקציה נבדקה בדפדפן ובבניית ה-bundle, לא על טלפון אמיתי.
